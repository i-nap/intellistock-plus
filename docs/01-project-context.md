# Project Context

This project is **IntelliStock+**, a full-stack warehouse management system.

The system manages inventory, products, suppliers, orders, inventory movement logs, notifications, reports, and auto-reordering. The frontend is built with **Next.js** and **shadcn/ui**. The backend is built with **Spring Boot**.

The visual style should follow the provided dashboard reference:

- Clean fintech/SaaS dashboard feel
- Soft off-white background
- Rounded cards
- Dark text
- Lime/neon green accent
- Light cyan secondary accent
- Minimal shadows
- Data-heavy but still readable
- Modern, spacious UI
- Dashboard-first layout

Avoid generic Bootstrap-looking UI. The design should feel polished, premium, and modern.
