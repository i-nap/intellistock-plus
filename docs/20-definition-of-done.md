# Definition of Done

A feature is done only when:

- UI matches the design direction
- API integration works
- Validation exists
- Loading state exists
- Error state exists
- Empty state exists where needed
- Constants are used for repeated strings
- Types/DTOs are clear
- Backend uses DTOs, services, and repositories correctly
- Tests are added for important logic
- No obvious security issue is introduced
- No large messy files are created
