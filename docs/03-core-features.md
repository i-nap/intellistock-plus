# Core Features

Build around these modules:

- Authentication and RBAC
- Dashboard
- Inventory Management
- Product Management
- Supplier Management
- Order Management
- Auto-Reorder Engine
- Notifications
- Reporting
- Inventory Logs / Audit Trail

## MVP Scope

- Login and register
- Role-based access
- Inventory CRUD
- Product CRUD
- Supplier CRUD
- Order creation and tracking
- Auto-reorder trigger
- Dashboard summary cards and charts
- Basic reports

## Advanced Features

Can be added later:

- OAuth2 login
- OTP verification
- Email notifications
- PDF reports
- WebSocket chat or live notifications
- ML-based demand prediction
- Payment integration
