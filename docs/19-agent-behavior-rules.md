# Agent Behavior Rules

When generating or editing code:

1. First understand the feature and existing structure.
2. Follow the existing project style if it already exists.
3. Keep files small.
4. Keep functions small.
5. Use constants instead of magic strings.
6. Use reusable components.
7. Add validation.
8. Add loading, empty, and error states.
9. Add tests for important logic.
10. Do not silently remove existing behavior.
11. Explain important changes briefly after editing.
12. Mention assumptions clearly.

When unsure, prefer a clean, boring, maintainable solution over a clever one.
